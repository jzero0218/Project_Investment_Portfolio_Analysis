# Project_Investment_Portfolio_Analysis

**Overview**


This project analyzes historical stock returns to evaluate portfolio performance, risk, and diversification opportunities using Python.
Status: Work in Progress (V0.1)


**Tools**


．Python


．Pandas & NumPy


．Matplotlib & Seaborn


．SciPy


**Current Analysis**


．Historical stock price analysis


．Daily returns and descriptive statistics


．Correlation and covariance analysis


．Portfolio variance and annualized volatility


．Annualized return and Sharpe Ratio


．Correlation heatmap visualization


**Key Findings**


．TSMC (2330.TW) and Yuanta Taiwan 50 ETF (0050.TW) show a strong positive historical correlation (r ≈ 0.91).


．VOO shows relatively low historical return correlations with the selected Taiwanese assets.


．A portfolio consisting of 60% TSMC and 40% 0050 has an estimated annualized arithmetic return of 35.46% and annualized volatility of 25.79% over the analyzed sample. Sharpe Ratio = 1.31.

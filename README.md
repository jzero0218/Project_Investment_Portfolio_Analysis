**Key Findings**


．TSMC (2330.TW) and Taiwan 0050 ETF (0050.TW) show a strong positive historical correlation (r ≈ 0.91).


．VOO shows relatively low historical return correlations with the selected Taiwanese assets.


．A portfolio consisting of 60% TSMC and 40% 0050 has an estimated annualized arithmetic return of 35.46% and annualized volatility of 25.79% over the analyzed sample. Sharpe Ratio = 1.297.
